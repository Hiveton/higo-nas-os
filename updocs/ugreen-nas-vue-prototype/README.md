# UGREEN NAS Vue Prototype

这是一个放在 `updocs` 下的独立 Vue/Vite 前端原型，用于根据绿联 NAS 网页端的功能结构和 UI 风格重建 HiGoNAS 桌面体验。

## 运行

```bash
npm install
npm run dev -- --port 5198
```

打开：

```text
http://127.0.0.1:5198/
```

## 构建

```bash
npm run build
```

## 已实现

- 源站风格深色 NAS 桌面壁纸、蓝色曲面背景与顶部状态栏
- 18 个桌面应用入口
- 桌面应用按源站三列宫格排布，并按源站第一屏重新校准应用图标配色
- 多窗口打开、关闭、聚焦、拖拽、调整大小、最大化、最小化 Dock
- 顶部左侧源站式窗口快捷栏：桌面、应用库、已打开窗口图标，可快速显示桌面、恢复窗口、聚焦窗口
- 窗口标题栏帮助按钮会打开当前应用上下文帮助，并可跳转帮助中心或提交诊断
- 活动窗口高亮，标题栏双击可最大化/还原
- 显示桌面、全部恢复、窗口左右贴靠
- 应用库、小组件视图、桌面右键菜单
- 应用库和小组件切换会临时进入桌面层，不最小化窗口，点应用/窗口图标后恢复窗口层
- 桌面/应用右键菜单会自动避开屏幕边缘，底部右键时菜单完整可见
- 顶部 CPU/RAM/网络可打开系统状态面板
- 桌面应用支持选中态和右键应用菜单
- 桌面壁纸主题切换、帮助面板、右键菜单动作反馈
- Esc 关闭弹层，Command/Ctrl+K 打开全局搜索
- 全局搜索使用独立搜索词，不会污染 App Center 当前分类；未安装应用从搜索/应用库进入时会先走安装确认
- 小组件可点击打开对应模块，桌面操作会出现轻量 toast 反馈
- 控制面板：连接与访问、通用设置、系统服务，各入口可搜索/切换详情，页签与配置动作有通知反馈
- 控制面板：首页宫格、二级详情页、配置抽屉、开关/滑杆/保存/测试/推荐配置动作
- 控制面板二级页左上宫格按钮可返回首页
- 文件管理：源站 1100x642 浮窗、个人/共享/用户/标签左侧树、两层工具栏、源站默认 Music/Photos 两行列表、文件表格、选中态、行菜单、筛选、排序、刷新、全选、拖拽上传、空状态
- 文件管理路径栏支持回车定位，后退/前进按历史启用，双击文件夹可进入模拟子目录并刷新当前路径
- 应用中心：源站风格社区 banner、分类、搜索、真实 41 个应用目录、源站首页应用顺序、安装/更新确认、权限确认、安装进度队列、打开状态、已安装过滤、可保存的设置弹窗
- 任务/通知/搜索弹层，通知角标、可清空、可单条关闭，任务可暂停/继续/取消并更新状态与进度视觉
- 用户中心菜单、电源确认、锁屏/解锁流程
- 文件管理上传、新建文件夹、批量下载、复制到、移动到、共享链接、文件重命名、标签编辑、删除确认、文件详情抽屉
- 文件管理左下回收站入口可直接打开回收站窗口
- 应用中心详情弹窗、权限/版本/数据目录展示、更新检查/权限审计/卸载确认、安装后通知
- 统一危险操作确认框：文件删除、应用卸载、设备重启/关机
- 通用应用页：概览、任务、设置、日志标签切换，功能卡可进入操作流程，设置页支持应用级开关、资源限制、权限摘要、推荐值和保存反馈
- 移动宽度响应式布局

## 说明

该原型使用本地 mock 数据，不连接真实绿联服务，也不连接项目后端。源站中的品牌图、设备图和应用图标均以本地 CSS/开源图标近似重建，避免热链或复制专有资产。
