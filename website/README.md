# HiGoOS Website

HiGoOS NASOS 官网独立前端项目。页面是单页完整官网，视觉方向参考飞牛官网的简约产品发布页：白底、大标题、短卖点、主按钮和清晰的信息层级。核心表达是“AI 原生家庭 NAS 系统”，而不是普通网盘或泛 SaaS 页面。

## 运行

```sh
npm ci
npm run dev
```

生产构建与预览：

```sh
npm run build
npm run preview
```

本地静态验收：

```sh
npm test
```

## 页面范围

- 首屏 Hero：HiGoOS 品牌、短卖点、查看产品 / 体验桌面 CTA。
- 产品能力：文件管理、存储管理、相册媒体、备份同步、下载中心、Docker、远程访问、设备监控。
- AI 原生：AI 文件管家、AI 助手、Agent 工作台、语义搜索、自动整理建议。
- 安全治理：预览影响、风险分级、确认执行、审计记录、一键回滚。
- 应用生态：应用中心、Docker / Compose、共享协议、远程访问。
- 部署体验：局域网发现、设备确认、网络配置、Web 初始化。

## 资产边界

- 首页不做产品图片宣传，不引用、不保留产品 UI 截图切图。
- 官网表达依赖文案、图标、排版、留白和响应式布局。

## 交互边界

官网不接后端 API。交互仅包含页面锚点、外部打开实际桌面、hover 和响应式布局。

- `查看产品`：滚动到产品能力区。
- `体验桌面`：新窗口打开 `http://10.211.55.3:8080/`。

## 验收标准

- `npm test` 通过，确认关键文案、CTA、入口存在，并阻止首页重新引用产品宣传图片。
- `npm run build` 通过，确认 TypeScript 和 Vite 生产构建可用。
- 桌面 `1440x900` 和移动 `390x844` 检查无横向溢出。
- `npm test` 会阻止首页重新引用产品 UI 截图。
