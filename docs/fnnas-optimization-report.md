# fnOS 文档对齐优化报告

日期：2026-05-13

## 参考范围

依据飞牛帮助中心 `https://help.fnnas.com/` 首页和侧栏“查看更多”后的文档目录，当前界面必须覆盖以下一级功能：

- 从这里开始：安装初始化、App 连接、飞牛 TV、虚拟机安装、异常处理。
- 存储管理：创建存储空间、硬盘休眠、SSD 缓存。
- 飞牛影视：影视安装、媒体库、影视账号、Infuse/VidHub、路径权限、刮削修正。
- 相册：手机备份、共享相册、AI 相册、鸿蒙备份、Google Photos 导入、视频播放问题。
- 远程访问：FN Connect、权益管理。
- 系统设置：用户、无线网卡、蓝牙配网、端口、配置备份还原、2FA、邮件通知。
- 文件管理：共享给用户、外部分享链接、团队文件、父子级权限。
- 文件共享协议：WebDAV、NFS、SMB 3 多通道、DLNA。
- 虚拟机：安装使用、硬件直通。
- 飞牛同步：功能介绍、按需同步、常见问题。
- 备份：加密备份。
- iSCSI：名词、基础功能、用户组、CHAP、常见问题。
- 硬件：官方硬件、合作机型、ARM/刷机资料。
- AI & OpenClaw：微信、钉钉、飞书机器人。
- 安全性：安全披露、漏洞报告奖励计划。
- 更多：联系方式、账号差异、管理员与普通用户权限、商业说明。

## 当前工程偏差

- 桌面入口偏差：项目原有 14 个应用入口缺少文件共享协议、虚拟机、飞牛同步、iSCSI、硬件中心、OpenClaw 独立入口。
- 存储管理偏差：已有容量、SMART、快照、修复，但缺创建存储空间、选择文件系统、选择硬盘、存储模式、配额、格式化确认、删除空间和 SSD 缓存入口。
- 文件管理偏差：已有搜索、预览、标签、分享，但缺上传、下载、新建文件夹、复制、重命名、删除、恢复、团队共享、外链管理、父子权限入口。
- 相册/影视偏差：已有媒体任务，但缺手机备份、共享相册、AI 相册模型、Google Photos 导入、影视账号、客户端接入和刮削修正入口。
- 远程访问偏差：已有通道/MFA/设备，但缺权益管理和分享链安全关联入口。
- 系统设置偏差：已有设置分类，但缺蓝牙配网、无线网卡、端口、邮件、2FA、配置备份还原的集中入口。
- 安全偏差：已有风险/审计，但缺安全披露、漏洞报告、2FA 操作闭环入口。
- 备份/同步偏差：已有备份任务，但飞牛同步和按需同步应是独立业务入口。
- iSCSI/虚拟机偏差：原项目没有独立界面，必须新增界面入口。

  - 存储管理：存储空间、磁盘缓存、iSCSI。
  - 备份同步：备份、飞牛同步。
  - 相册媒体：相册、影视。
  - 远程访问：FN Connect、文件共享协议。
  - 安全中心：安全治理、文件共享。
  - 系统设置：系统配置、远程访问、AI。
  - 应用中心、Docker、设备监控、Agent、AI 管家均增加对应功能入口。

## 后端阶段待接 API

2. 文件上传/下载/复制/移动/重命名/删除/恢复、外链管理、团队权限。
3. SMB/NFS/WebDAV/DLNA 启停与配置。
4. 飞牛同步任务、按需同步、冲突处理。
5. iSCSI Target/LUN/CHAP/用户组。
6. 虚拟机创建、镜像、OVS、硬件直通、日志。
7. OpenClaw 机器人配置和权限审批。
8. 安全披露、漏洞报告、2FA、邮件通知、配置备份还原。
